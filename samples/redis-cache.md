# Кэширование в Redis

Кэш хранит результат тяжёлой операции, чтобы не выполнять её повторно. Redis держит данные в памяти
и отвечает быстрее, чем обычная база данных на диске.

## Стратегия cache-aside

Приложение сначала ищет значение в кэше. Если его нет, приложение обращается к базе данных и
сохраняет ответ в кэш с ограниченным временем жизни.

```python
value = redis.get(key)
if value is None:
    value = load_from_database(key)
    redis.setex(key, 300, value)
```

## Сброс кэша

Самое сложное в кэшировании — вовремя сбросить устаревшие данные. Для поисковых результатов удобно
хранить номер версии индекса в ключе: после изменения документов старые записи просто перестают
использоваться.
