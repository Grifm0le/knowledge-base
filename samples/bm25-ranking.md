# Как работает BM25

BM25 оценивает релевантность документа запросу. Метод учитывает три вещи: сколько раз термин
встречается в документе, насколько термин редкий во всей базе и какова длина документа.

## Отличие от TF-IDF

В TF-IDF оценка растёт вместе с частотой термина почти без ограничений. В BM25 рост замедляется:
десятое упоминание слова добавляет к оценке намного меньше, чем второе. За это насыщение отвечает
параметр `k1`, а параметр `b` управляет нормализацией на длину документа.

## Формула

```python
idf = math.log(1 + (n - df + 0.5) / (df + 0.5))
score = idf * tf * (k1 + 1) / (tf + k1 * (1 - b + b * dl / avgdl))
```

Обычно берут `k1 = 1.2` и `b = 0.75`. Такие значения хорошо работают на большинстве коллекций
документов, поэтому начинать стоит с них.
