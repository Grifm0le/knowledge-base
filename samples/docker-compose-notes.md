# Заметки по Docker Compose

Compose описывает несколько контейнеров в одном файле и запускает их одной командой. Это удобно для
локальной разработки: приложение, база данных и кэш поднимаются вместе.

## Основные команды

```bash
docker compose up -d
docker compose logs -f api
docker compose down
```

## Проверка готовности

Контейнер базы данных запускается не мгновенно, поэтому приложению нужно дождаться готовности.
Для этого в файле задают `healthcheck` и условие `service_healthy` в секции `depends_on`.

## Переменные окружения

Пароли и адреса не хранят в файле compose. Их выносят в файл `.env`, который не попадает в
репозиторий, а в репозиторий кладут пример `.env.example`.
