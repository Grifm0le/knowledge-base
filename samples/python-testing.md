# Тестирование на pytest

Модульный тест проверяет одну функцию в изоляции, интеграционный проверяет совместную работу
нескольких частей системы.

## Параметризация

Один тест можно запустить на разных входных данных через `parametrize`.

```python
@pytest.mark.parametrize("word, expected", [("документы", "документ"), ("поиск", "поиск")])
def test_stem(word, expected):
    assert stem(word) == expected
```

## Покрытие кода

Плагин `pytest-cov` показывает, какие строки не выполнялись во время тестов. Высокое покрытие не
гарантирует отсутствие ошибок, но показывает места, которые никто не проверял.
