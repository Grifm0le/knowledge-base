# Работа с Git

Каждая задача делается в отдельной ветке, а изменения попадают в основную ветку через слияние.

## Осмысленные коммиты

Сообщение коммита объясняет, что изменилось и зачем. Один коммит содержит одно логическое изменение,
поэтому его легко проверить и при необходимости отменить.

## Полезные команды

```bash
git switch -c feature/search
git log --oneline --graph
git diff --staged
```

Команда `git bisect` помогает найти коммит, после которого появилась ошибка: она делит историю
пополам и проверяет середину.
