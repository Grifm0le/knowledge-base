# Алгоритмы ранжирования

Документ описывает, как считается оценка документа. Код находится в `src/kb/scoring.py`, индекс в
`src/kb/index.py`, поиск средствами базы в `src/kb/storage/repository.py`.

## Подготовка текста

Запрос и документ проходят одну обработку (`src/kb/textproc.py`): приведение к нижнему регистру,
разбиение на слова, удаление стоп-слов и стемминг алгоритмом Snowball для русского и английского
языков. Документ разбирается на пять полей: название, подзаголовки, теги, текст и код.

## Обозначения

| Обозначение | Смысл |
|---|---|
| `N` | число документов в индексе пользователя |
| `df(t)` | число документов, где встречается термин `t` |
| `c(t, d, f)` | сколько раз термин `t` встречается в поле `f` документа `d` |
| `w(f)` | вес поля `f` |
| `qtf(t)` | сколько раз термин `t` встречается в запросе |
| `tf(t, d)` | взвешенная частота: сумма `w(f) * c(t, d, f)` по полям |
| `L(d)` | взвешенная длина: сумма `w(f) * длина поля f` по полям |
| `avgL` | средняя взвешенная длина документа в индексе |

Веса полей по умолчанию: название 3, подзаголовки 2, теги 2, текст 1, код 0,5. Термин, который
встречается только в полях с нулевым весом, совпадением не считается.

## TF-IDF

```
idf(t) = ln((N + 1) / (df(t) + 1)) + 1
score(d) = сумма по t: ln(1 + tf(t, d)) * idf(t) * qtf(t) / sqrt(L(d))
```

Логарифм частоты не даёт длинному повторению одного слова перевесить остальные слова запроса.
Деление на корень из длины уравнивает короткие и длинные документы.

## BM25

```
idf(t) = ln(1 + (N - df(t) + 0,5) / (df(t) + 0,5))
norm(d) = k1 * (1 - b + b * L(d) / avgL)
score(d) = сумма по t: idf(t) * tf(t, d) * (k1 + 1) / (tf(t, d) + norm(d)) * qtf(t)
```

Параметры по умолчанию: `k1 = 1,2`, `b = 0,75`. Частота насыщается: каждое следующее вхождение слова
добавляет к оценке меньше предыдущего. Параметр `b` задаёт силу нормализации на длину.

## Гибридный метод

Оценки разных методов лежат в разных шкалах, поэтому сначала приводятся к диапазону от 0 до 1:

```
norm(score, d) = (score(d) - min) / (max - min)
hybrid(d) = сумма по методам m: weight(m) * norm(score_m, d)
```

Веса по умолчанию: BM25 0,7, TF-IDF 0,3. Если у всех найденных документов оценка одинакова,
нормализованная оценка равна 1.

## Полнотекстовый поиск PostgreSQL (`pgfts`)

Колонка `search_vector` хранит предварительно обработанный текст: название с весом A, подзаголовки и
теги с весом B, текст с весом C, код с весом D. Поиск использует индекс GIN и функцию `ts_rank_cd`.
Слова запроса соединяются через ИЛИ, чтобы документ находился и при совпадении одного слова.

Веса PostgreSQL по умолчанию: `{D 0,1; C 0,2; B 0,4; A 1,0}`. Функция принимает значения от 0 до 1,
поэтому заданные пользователем веса делятся на наибольший из них. Подзаголовки и теги находятся в
одной группе B, для неё берётся больший из двух весов.

## Настройка весов

Параметры метода `GET /api/v1/search`, значения от 0 до 100:

| Параметр | Что задаёт |
|---|---|
| `w_title`, `w_headings`, `w_tags`, `w_body`, `w_code` | вес поля |
| `hybrid_bm25`, `hybrid_tfidf` | вклад метода в гибридную оценку |

Незаданный параметр сохраняет значение по умолчанию. Если все веса равны нулю, запрос отклоняется.
Выдача с разными весами кэшируется отдельно. Пример: найти прежде всего по названию.

```bash
curl -H "Authorization: Bearer $TOKEN" \
  "https://127.0.0.1:8443/api/v1/search?q=индексы&scorer=hybrid&w_title=10&w_body=0.5&hybrid_bm25=1&hybrid_tfidf=0"
```

## Сложность

| Операция | Сложность | Пояснение |
|---|---|---|
| Индексация документа | `O(T)` | `T` — число слов документа |
| Поиск | `O(P + n log n)` | `P` — сумма длин списков документов по терминам запроса, `n` — число найденных |
| Память индекса | `O(U + S)` | `U` — число разных терминов, `S` — сумма длин всех списков |

Замеры на растущем корпусе делает `tools/bench_scale.py`, результаты лежат в `runs/`.

## Как добавить метод

```python
from kb.scoring import Scorer, register_scorer


@register_scorer
class MyScorer(Scorer):
    name = "my-method"

    def score(self, query_terms, index): ...
```

После этого метод доступен в параметре `scorer`. Гибридный метод может включить его через
`method_weights`.
